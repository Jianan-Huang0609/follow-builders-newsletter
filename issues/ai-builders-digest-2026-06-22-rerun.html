Open Weights at a Crossroads / 开源模型的十字路口

播客和推特传来同一个信号——开源模型的数量可能已经过了顶峰。但 Aaron Levie 认为，只要差距不拉大，这对应用层反而是利好。

Unsupervised Learning

中文

在一期信息密度极高的「AI Vibe Check」播客中，Ari（Datalogy CEO，前 DeepMind/Meta 研究员）和 Rob（Radical Ventures）给出了一个冷静的判断：未来开源模型会越来越少。「我对开源模型数量的前景比之前悲观多了……我们可能已经过了开源模型的峰值。」原因很简单——财务上不划算。一旦一个实验室通过开源发布获得了足够的 credibility，他们就想卖推理服务了。开源模型等于拆自己的台。

English

In a wide-ranging 'AI Vibe Check' episode, Ari (CEO of Datalogy, former DeepMind/Meta researcher) and Rob (Radical Ventures) deliver a sobering assessment of open weight AI: 'I am a lot more bearish on how many open models there will be going forward... we probably hit the peak number of open models.' The financial incentives simply don't work—once a lab achieves credibility through open releases, they want to sell hosted inference. Releasing open weights undermines that business entirely.

Rob adds that even the traditional open-weight champions are pulling back: Meta seems unlikely to continue its strategy, and Chinese labs like Qwen and DeepSeek are now keeping their best models behind APIs while open-sourcing only smaller, less capable versions.

A separate but related thread: Anthropic's Fable release sparked backlash because of a 'silent refusal' mechanism. As Ari explains: 'It doesn't give you a refusal, it doesn't say I'm not going to help you with this, it just does a poor job on that without you knowing.' Many see this as competitive positioning—limiting Fable's use for AI development—rather than a genuine safety measure. Ari notes that open models with good scaffolding were able to find many of the same vulnerabilities that Mythos found, undermining the safety rationale.

I am a lot more bearish on how many open models there will be going forward... we probably hit the peak number of open models and it's now going to kind of get less and less. Because the financial incentives just don't make sense.

English

Box CEO Aaron Levie offers a counterpoint to the open-weights pessimism: 'Pretty remarkable what's happening with open weights AI right now. We're seeing models achieve SOTA results on specific tasks, and getting close to frontier on some areas of coding and other domains.'

AI-Native Roles / AI 原生职业

当工程师从 IC 变成 Agent 管理者，PM 也分化为两派——AI 正在重写每个职业的定义，而保持认知更新变成了生存技能。

中文

Madhu Guru 对 AI 时代 PM 角色的身份危机给出了一个精准诊断：「工程团队已经找到了 AI 原生的接口——SWE agent 极大地放大了个人产出。公司也在让 PM 用 AI，但没有真正升级这个角色。」

他描绘了两种正在分化的 PM 画像。旧派 PM 用 AI 加速旧工作：更多的 PRD、更多的策略文档、更多的材料——产出很多，判断很少。Builder PM 则用 AI 扩展自己在整个产品生命周期中的角色：用 agent 做市场和用户研究、直接查询日志、生成多个竞争方案然后精选最优。他们的产出越来越偏向原型而非文档。「工程师对 demo 的反馈远比文档更积极。」他说，「这个角色正在向 Builder PM 靠拢。」

PM 角色也在经历身份危机。工程找到了 AI 原生接口——SWE agent 大幅放大个人产出。公司让 PM 用 AI 但没有升级这个角色。

Builder PM 用 AI 扩展整个产品生命周期的角色。产出越来越偏原型而非文档——工程师对 demo 反馈比文档积极得多。

English

Madhu Guru delivers a sharp diagnosis of the PM role's identity crisis in the AI era: 'Engineering has found its AI-native interface—SWE agents dramatically increase individual leverage. Companies are asking PMs to use AI, but they haven't evolved the role.'

He sketches two emerging archetypes. The Old-School PM uses AI to accelerate the old job: more PRDs, more strategy decks, more docs—lots of output, not much judgment. The Builder PM uses AI to expand across the entire product lifecycle: running agents for market and user research, querying logs directly, generating competing ideas, then curating the best ones. Their outputs are increasingly prototypes rather than docs. 'Engineers react far more constructively to demos than docs,' he notes. 'The role is moving much closer to Builder PMs.'

Compute Crunch Cascade / 算力紧缺的连锁反应

算力短缺不只是涨价——它可能让 API 服务本身消失，并在更深的层面推动芯片制造技术的范式转移。

UL
Unsupervised Learning
Unsupervised Learning Podcast
中文

这期 Unsupervised Learning 播客最令人不安的预测来自 Ari：「完全可以想象一个 Anthropic 因为算力极度紧张而直接切断 API 的世界。因为很明显，Claude Code 比 API 更赚钱，他们会优先保证 Code 的算力。」

这不是商业策略上的猜测——是物理约束。全球算力紧缺意味着前沿实验室可能被迫把最强模型留给自己用，而不是开放给外部 API 客户。OpenAI 已经在卖「期货」了——提前锁定推理 token 的保证配额——Ari 称之为「对所有依赖这些模型做产品的公司的巨大生存威胁。」

讨论还深入到了更底层的供应链。Rob 指出一个荒诞的现实：「世界上只有一家公司会做最先进的芯片，没有第二家会。」但颠覆正在酝酿：创业公司正在研发原子光刻（用原子束代替光来蚀刻晶体管，实现更小的特征尺寸）和 x 射线光刻（向电磁频谱更短波长方向推进）。两项技术都可能在本世纪 30 年代从根本上重塑芯片制造格局。

完全可以想象 Anthropic 因为算力极度紧张而切掉 API。Claude Code 比 API 更赚钱，他们会优先保证。

OpenAI 在卖推理 token 期货——提前锁定配额。这对所有依赖这些模型的 builder 是巨大的生存威胁。

不用光而用物质——叫原子光刻，用原子束来蚀刻芯片，分辨率更高。还有 x 射线光刻也在获得关注。

English

The most unsettling prediction from the Unsupervised Learning 'AI Vibe Check' comes from Ari: 'It is not hard to imagine a world in which Anthropic is so compute constrained that they actually cut off the API. Because obviously they're going to prefer Claude Code to the API with respect to how much money they make.'

This isn't speculation about a business strategy—it's about physics. The global compute crunch means frontier labs may be forced to reserve their most powerful models for their own products, not external API customers. OpenAI is already selling 'futures'—guaranteed access to inference tokens in advance—which Ari calls 'a huge existential threat to anybody that builds on top of these models.'

The conversation also explores the deeper supply chain. Rob notes that the world is in a bizarre state where 'there's one company that knows how to make cutting-edge chips, and no one else can do it.' But disruption is brewing: startups are working on atom lithography (using beams of atoms instead of light to print transistors, enabling much smaller features) and x-ray lithography (moving further on the electromagnetic spectrum for shorter wavelengths). Both could fundamentally reshape who controls chip manufacturing in the 2030s.

It is not hard to imagine a world in which Anthropic is so compute constrained that they actually cut off the API. Because obviously they're going to prefer Claude Code to the API with respect to how much money they make.

OpenAI starting to sell futures of like, hey, get guaranteed access to inference tokens going forward. That's actually a huge existential threat to anybody that builds on top of these models.

Rather than using light... using matter, it's called atom lithography, where you use a beam of atoms to print these features on the chips, which lets you get way lower resolution. There's also x-ray lithography getting a lot of momentum.
