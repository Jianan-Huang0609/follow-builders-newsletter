agent 的下一步不是再多一个 demo，而是能发现真实环境里的设备、数据和可用连接，并把它们组织起来。

中文

如果你是家庭自动化爱好者，可以试试把这段 prompt 发给 Claude Code / Codex（按自己的配置修改）： “你能不能嗅探家里的网络数据包，看看还有什么可以自动化？背景是：我们有一个 Hermes agent，已经能处理个人 Gmail、恒温器、DoorDash、Amazon 等很多事情。 我想看看还能连接什么。我们有一台 Apple TV，必要时可以和它对话来做 HomeKit 相关的事情，但没有运行 Home Assistant 的其他 bridge。 请完整列出你发现的设备，并研究它们如何连接到 agent。”

English

Nikunj Kothari suggests a revealing home-automation experiment: let Claude Code or Codex sniff the home's network traffic, inventory the devices it finds, and research how each one could connect to an agent. The interesting idea is that agent capability may be constrained less by a missing model feature than by how much of the user's physical and digital context is still disconnected.

If you are a home automation nerd, this is a fun prompt to try on Claude Code / Codex (edit based on your own setup): "Can you sniff network packets in our house and see what else can we automate? For context: We have a Hermes agent that runs a lot of things like the personal Gmail, thermostat, Doordash, Amazon etc. Trying to see what else we can connect to. We have an Apple TV that we can talk to if we need for HomeKit related stuff but no other bridge that runs home assistant. Give me a full list of devices that you find and research how they can be connected to an agent."

Theme 03

The Inference Stack Gets Serious / 推理底座进入硬仗

模型能力往下落地之后，速度、memory bandwidth 和 full-stack 芯片设计会成为产品体验的一部分。

NP
No Priors
Founder & CEO, Fractile · No Priors
中文

一句话结论：frontier AI 需要的可能不是今天 GPU 的更快版本，而是一整套为 frontier 模型设计的芯片栈。Fractile 创始人兼 CEO Walter Goodwin 认为，inference chip 应该围绕超大模型和超长 context 来设计，而 memory bandwidth 会是核心瓶颈。他的一个反直觉判断是：芯片市场看起来选择很多，实际上高度同质化，很多 accelerator 仍然共享 HBM、tensor core、先进封装和那几家制造伙伴。

真正难、也真正有机会的地方，是从理解 workload 的架构设计、front-end design，一直做到 physical design 和与晶圆厂的协作。Goodwin 的判断很具体：如果能在芯片结构上领先三到六个月，就可能赢下这段时间里的所有部署。

Fractile 是一家芯片公司。我们为世界上最大的模型打造非常非常快的 inference chip。

芯片领域的 frontier model 是：如果你能找到办法在结构上领先三到六个月，你就会赢下所有这些部署。

English

The takeaway: frontier AI may need a frontier chip stack, not just a faster version of today's GPU. Fractile founder and CEO Walter Goodwin argues that inference chips should be designed around huge models and long contexts, with memory bandwidth as a central constraint. His contrarian point is that the chip market looks more diverse than it really is: many accelerators still share HBM, tensor cores, advanced packaging, and the same small set of manufacturing partners.

The harder opportunity is full-stack ownership, from workload-aware architecture and front-end design down to physical design and foundry interaction. Goodwin's framing is refreshingly concrete: a small structural lead in chips can translate into winning deployments for the next three to six months.

Fractile is a chip company. We build very, very fast inference chips for the world's largest models.

The frontier model for the chip space is if you can just find a way to structurally carve out a three to six months advantage, you will be winning all of those deployments.
