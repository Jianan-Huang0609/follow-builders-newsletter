中文

Vercel CEO Guillermo Rauch 宣布了一项实用新功能（127 赞）：「Vercel CLI 现在允许你：创建 AI Gateway API 密钥、用 --budget 参数限制支出上限、用 --refresh-period 设置配额刷新周期。把它想象成 AI token 的虚拟信用卡。」

这是对日益增长的 AI token 支出管理问题的基础设施级回应。随着团队部署能自主烧 token 的 agent，给开发者可编程的预算控制变得和 AWS 成本分配标签一样必要。虚拟信用卡这个比喻很准：就像给员工发一张有额度限制的公司卡，现在给 agent 发一张有额度限制的 API 密钥。

English

Vercel CEO Guillermo Rauch announced a practical new feature (127 likes): 'Vercel CLI now allows you to: create AI Gateway API keys, pass a --budget to cap their spend, set a --refresh-period for the quota. Think of it as virtual credit cards for AI tokens.'

This is the infrastructure response to the growing problem of AI token spend management. Applied AI 策略 / Applied AI Strategy

Aaron Levie 论「不可训练的角落」。Zara Zhang 指出非技术用户的真正障碍是「不知道该问什么」。Josh Woodward 预测软件需求将「超乎想象」。

中文

Box CEO Aaron Levie 延续了他关于上下文的论点（278 赞），推荐了一篇关于「不可训练的角落」的文章：「一个应用通过在不可训练的角落做不光彩的工作来赢得位置：整理公司的私有数据、理解谁能访问什么、内化那些存在于 Slack 消息而非教科书中的业务规则。」

这是 Levie 昨天论点的延伸：上下文不仅是不可替代的，它特指那种混乱的、私有的、非结构化的制度性知识——任何基础模型都无法摄入。「不可训练的角落」是应用层 AI 公司应该构建护城河的地方——这类问题不能通过更好的预训练来解决，只能通过更深地嵌入组织工作流来解决。

一个应用通过在不可训练的角落做不光彩的工作来赢得位置：整理公司的私有数据、理解谁能访问什么、内化那些存在于 Slack 消息而非教科书中的业务规则。

English

Box CEO Aaron Levie continued his thesis on context (278 likes), recommending a post about the 'untrainable corner': 'An application earns its place in the untrainable corner by doing unglamorous work: arranging a company's private data, understanding who has access to what, and internalizing business rules that live in Slack messages, not textbooks.'

This extends Levie's argument from yesterday: context isn't just irreplaceable, it's specifically the messy, private, unstructured institutional knowledge that no foundation model will ever ingest. The 'untrainable corner' is where applied AI companies should build their moat — it's the set of problems that can't be solved by better pre-training, only by deeper integration into organizational workflows.
