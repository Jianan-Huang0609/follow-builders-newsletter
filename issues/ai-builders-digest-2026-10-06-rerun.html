The New Builder Surface / Builder 的新工作面

工具变强之后，稀缺的不是“能不能做出来”，而是能否定义正确的问题、保持真实沟通，并把上下文交给 agent。

中文

Guillermo Rauch 给 AI 辅助写作划出了一条很清楚的边界：README、博客和 tweet 要为人写，内部文档则可以用 agent 更容易处理的 AI English。重点不是纠结文风，而是承认两种文本服务于两种接口：面向人的文字负责建立连接，面向 agent 的文档负责传递上下文。

README 完全是手写的，因为它是给人看的。文档内部则是 AI English，因为它们是给 agent 用的。 博客、tweet、README 都是人与人的沟通。重点甚至不是有没有 em dash，而是这是你通过文字和其他人建立连接的讲故事时刻。

English

Guillermo Rauch draws a clean boundary for AI-assisted communication: write READMEs, blogs, and tweets for humans, but let internal documentation speak in AI English for agents. The point is not style policing. Human-facing writing is where a story connects people; agent-facing documentation is an interface for machines.

The 𝚁𝙴𝙰𝙳𝙼𝙴 is fully written by hand, because it's for human consumption. The documentation internals are AI English, because they're for agents. Blogs, tweets, READMEs: human communication.
