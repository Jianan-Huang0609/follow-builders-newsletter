Theme 01

Agents Become Work Systems / Agent 变成工作系统

下一代 agent 的核心不是更像聊天机器人，而是能在工具、数据和人类监督之间完成一整段工作。

中文

Box CEO Aaron Levie 认为，专门负责某个任务或领域的 autonomous systems，正在成为超越 LLM wrapper 的新形态。更强的 tool use 和 computer use 让 agent 能操作外部系统，模型能力提升则让它在法律、生物、代码安全、供应链等领域做出更好的判断。

真正补齐这件事的是 harness：sandbox、文件系统、数据管道，以及支持人类监督的 UX。把这些基础原语组合起来，agent 才能在企业工作流里长时间运行。

一种新的 AI 形态正在出现：专门负责特定任务或领域的 autonomous systems。

harness 和周边基础设施让 agent 能运行更长时间。

English

Box CEO Aaron Levie argues that autonomous systems dedicated to specific tasks or domains are the next form factor beyond LLM wrappers. Better tool and computer use lets agents operate across external systems, while stronger models improve judgment in domains such as legal, biology, security, and supply chains.

The missing layer is the harness: sandboxes, file systems, data pipelines, and UX for human oversight. Together, these primitives make longer-running agents practical for enterprise workflows.

We clearly have an emerging form factor for what AI might look like for the foreseeable future as autonomous systems dedicated to specific tasks or domains.

The harnesses and surrounding infra — sandboxes, file systems, data pipelines, etc. — allows for longer running agents.

The unglamorous detail matters: persistent context is becoming a product primitive.

You can now cache for 12h in the API and for logged in users across Codex & Work we keep cache forever.

From Threads to Swarms / 从线程到 agent swarm

当单个模型不再是唯一计算单元，协作结构本身就成了新的性能杠杆。

中文

Inference time scaling → Subagents → Agent Swarms，很像 CPU Threads → Multi-core CPUs → Multi-Node Distributed Systems。历史总会押韵。

English

Aditya Agarwal sees a familiar systems pattern in the progression from inference-time scaling to subagents to agent swarms: it rhymes with CPU threads, multi-core CPUs, and multi-node distributed systems. The implication is less about a catchy analogy than about a design direction: coordination and distribution will become first-class engineering problems.

Inference time scaling → Subagents → Agent Swarms looks an awful lot like CPU Threads → Multi-core CPUs → Multi-Node Distributed Systems. History rhymes well.
