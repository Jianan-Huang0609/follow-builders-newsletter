Theme 02

Context Is the Product / 上下文就是产品

企业 agent 的瓶颈越来越不是模型会不会推理，而是能不能在权限边界内找到正确的资料。

中文

Box CEO Aaron Levie 预计，企业里与数据和系统协作的 agent 数量，最终会达到今天员工数量的 100 倍。每次部署最后都绕不开一个问题：agent 能不能拿到做判断、研究或执行任务所需的上下文？

企业约 90% 的数据是非结构化的，因此 Box 正与 NVIDIA 合作，把 lexical search 和 semantic search 结合起来，同时遵守权限、安全和数据治理。核心并不复杂：只有在正确的 agent 找到正确的文件时，文件才真正对 agent 有用。

企业里与数据和系统协作的 agent 数量，会达到今天员工数量的 100 倍。

企业 90% 的数据是非结构化数据，我们需要让 agent 有效访问这些关键企业内容。

English

Box CEO Aaron Levie expects enterprises to have 100 times more agents working with their data and systems than people do today. Every deployment still comes down to one question: can the agent retrieve the context needed to decide, research, or act?

Because roughly 90% of enterprise data is unstructured, Box is partnering with NVIDIA on context retrieval that combines lexical and semantic search while respecting access controls, security, and governance. The pitch is simple: files become useful to agents only when the right agent can find the right file.

We’re going to have 100X more agents in the enterprise working with our data and systems than even people do today.

90% of the data in an enterprise is unstructured data... we need effective ways for agents to get access to this critical enterprise content.
