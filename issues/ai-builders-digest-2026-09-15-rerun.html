Theme 02

Proof Before Autonomy / 先验证，再放权

agent 做得越多，系统越不能只靠“相信它”；proof-checker、linters 和细粒度的数据权限会成为生产力的一部分。

中文

Guillermo Rauch 把新的瓶颈说得很直白：agent 的能力上限，取决于你给它配了什么 proof-checker、compiler、type system 和 linter。他举的例子是 shadcn/lint，帮助 agent 遵守设计系统的规则。

更大的判断是：verifier 和 skill 正在变成新的 framework。当 agent 生成的内容多到人根本看不完时，系统必须让错误输出更难产生。

English

Guillermo Rauch puts the new bottleneck plainly: agents are only as good as the proof-checkers, compilers, type systems, and linters around them. His example, shadcn/lint, helps agents stay within the rules of a design system.

The broader point is that verifiers and skills are becoming the new frameworks. When the agent can generate more output than a human can inspect, the surrounding system has to make wrong output harder to produce.

Box CEO Aaron Levie 认为，企业安全正在进入一个新的平衡期：agent 对公司系统的使用量可能是人的 100 倍，但如果给它无限权限，数据就很难真正控制；如果全部锁死，AI 的生产力收益又出不来。

Box 的做法是基于文档分类做细粒度控制，再识别并拦截异常的 agent 访问。重要变化在于，权限管理不再只是“允许/拒绝”，而要理解 agent 正在怎样使用信息。

在 agent 对企业系统的使用量达到过去人类 100 倍的世界里，保护企业数据会成为 21 世纪最复杂的安全和治理挑战之一。 在 AI 世界里，安全收益和生产力收益密不可分。给 agent 太多不受限制的信息访问权，很难真正控制和保护数据；反过来，如果把一切都锁死，也不会得到真正的 AI 生产力收益。 我们需要用更智能的新方式保护企业里的系统、环境，以及结构化和非结构化数据，更新安全和治理方法。 以 Box 为例，我们正在构建保护企业数据和 agent 使用这些信息的新方法。Box Shield 最近的一项更新，是根据文档分类等级，细粒度控制 agent 可以和不可以处理哪些内容。我们也在开发其他功能，在 agent 以异常方式访问或使用数据时自动检测、提醒或拦截。 而这只是开始。整个行业还会出现更多创新，重新思考 AI agent 世界里的信息保护。

English

Box CEO Aaron Levie argues that enterprise security is entering a new balancing act: agents may use company systems 100 times more than people did, but giving them unrestricted access makes data impossible to control. Lock everything down, and the productivity gains disappear.

Box's response is granular control based on document classification, plus detection and blocking for unusual agent access. The important shift is from a binary permission model to governance that understands what an agent is doing with information.

Protecting enterprise data in a world where agents are using our systems 100X more than people ever did is going to be one of the more complex security and governance challenges of the 21st century. Importantly, security and productivity gains are inexorably linked in the world of AI. We’re also working on other features that can automatically detect and alert (or block) when data is being accessed or used in unusual or anomalous ways by agents. And this is just the start. There’s a ton more innovation coming across the entire industry - from the labs like OpenAI or Anthropic; security platforms like Palo Alto Networks, Cisco, CrowdStrike, Okta; or startups like Enclave, Method, Alterion, Runlayer, and many many others - to rethink how we protect information in the world of AI agents. Compute for Agents / 给 Agent 重新造 Compute

当 agent 从一次调用变成后台工作者，基础设施的单位也会变化：不是给人提供一个页面，而是给一群持续工作的 agent 提供新的运行原语。

中文

Guillermo Rauch 介绍了 Vercel 面向 agent 的新 compute 方向：Fluid 家族覆盖 Functions、Containers、Sandbox 和 Builds，由 Google Cloud Run 的创建者 Steren 负责。他的判断是，serverless 是云计算的上一章，而 agent 需要专门为自己设计的新 compute 原语。

这个区分很有用。agent 不只是需要一个处理请求的地方，还需要能随着任务展开去 build、运行、暂停、恢复并隔离工作的环境。

欢迎 Google Cloud Run 的创建者 Steren 加入 Vercel。 他将负责 Fluid 计算产品家族（Functions、Containers、Sandbox、Builds）。 Serverless 是云计算的上一章，Steren 曾在 Google 帮助定义这一范式。 Agent 是下一个前沿，它们需要专门为 agent 设计的新 compute 原语。很高兴由 Steren 再次领导这次转型。

English

Guillermo Rauch describes Vercel's new compute direction around agents: Fluid is expanding across Functions, Containers, Sandbox, and Builds, led by Steren, the creator of Google Cloud Run. His framing is that serverless was the last chapter of cloud, while agents need new compute primitives designed for them.

That is a useful distinction. Agents do not just need a place to serve a request; they need environments that can build, run, pause, resume, and isolate work as it unfolds.

Welcoming Steren, creator of Google Cloud Run, to Vercel. He will lead the Fluid family of compute products (Functions, Containers, Sandbox, Builds). Serverless was the last chapter of the cloud, and Steren helped define the paradigm at Google. Agents are the next frontier, and they require new compute primitives designed for them. Excited for Steren to lead this transition once again.
