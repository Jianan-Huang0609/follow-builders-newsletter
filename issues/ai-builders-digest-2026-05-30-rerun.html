Theme 02

Agent Security / Agent 安全

当 coding agent 拥有你的数据库权限，传统的规则引擎不够用了。Onyx 在训练「看管 agent 的 agent」。

MB
Maxim Bar Kogan (CEO, Onyx Security)
KnowPriars Podcast
中文

Onyx Security CEO Maxim Bar Kogan 点出了核心矛盾：自主 coding agent 需要你的生产环境权限才能发挥作用——但这意味着它们也能删你的数据库。「我们想让 Claude Code 做一件能帮 DevOps 团队省大把时间的事。但如果 Claude Code 在干别的任务时突然觉得该把数据库删了重建——我们真不想让它这么干。」

企业 agent 使用现状：超过 50% 是自主 coding agent。传统的安全工具（端点、API、网络）看不到这个问题——它们无法区分同一个凭据下的合法 agent 操作和危险操作。

Onyx 的做法：训练专用小模型做第一道过滤，只在有可疑迹象时才升级到更强模型。「你要训练非常聪明的模型，把什么危险的直觉烧进去，这样它们不会频繁调用昂贵模型。」在保持覆盖面的同时控制成本和延迟。

新兴威胁面：「漏洞发现的成本正在暴跌。」以前安全研究员要花几个月的事，现在 agent 几分钟搞定。Bar Kogan 谈到的每个 CSO 都在「恐慌」——这是一整块随 AI 能力而放大的新攻击面。

我们想让 Claude Code 做一件帮 DevOps 省大把时间的事。但如果它觉得该删了数据库重建——我们真不想让它那么干。

漏洞发现成本暴跌。每个 CSO 都在恐慌。

English

Maxim Bar Kogan, CEO of Onyx Security, frames the core problem: autonomous coding agents need your production permissions to be useful — but that means they can also delete your database. 'We want to tell Claude Code to do something that will save our DevOps team a lot of time. But if Claude Code is working on an unrelated task and suddenly thinks the right thing to do is delete our database and recreate it — maybe we don't want that to happen.'

The enterprise breakdown: over 50% of agent usage is now autonomous coding agents. Traditional security tools (endpoint, API, network) don't see the problem — they can't distinguish between a legitimate agent action and a dangerous one when both use the same credentials.

Onyx's approach: train specialized small models to act as a first-pass filter, then escalate to more capable models only when something looks suspicious. 'You want to train very smart models that bake in the intuition of what's dangerous, so they don't call the expensive model too much.' This keeps costs and latency low while maintaining coverage.

The emerging threat vector: 'the plummeting cost of vulnerability finding.' What took security researchers months now takes agents minutes. Every CSO Bar Kogan talks to is 'freaking out' about this — it's a whole new attack surface that scales with AI capability.
