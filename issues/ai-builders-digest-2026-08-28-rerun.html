Software × Agents: The Enterprise Playbook / 软件与 Agent 的合流

企业级信号很清楚：agent 不会取代软件，而是和软件一起把 IT 蛋糕做大——前提是你得掌握底座。

中文

Box CEO Aaron Levie 借这周的科技公司财报电话会，对「软件 vs agent」的争论给出了一个反直觉的结论：它们不是对手，是互补。

软件提供确定性的护栏——数据怎么管、权限怎么治理、工作流怎么保持一致。Agent 在这些系统里干活，以人类团队从未有过的规模执行任务。正因如此，agent 越扩展，护栏反而越重要。

他的结论是：最好的 agent 会部署在成熟的软件平台内部（Salesforce、Box、Harvey、ServiceNow），这些平台能用垂直领域特有的 evals 和上下文来优化它们。最终结果是软件和 AI 的采用率一起上升，IT 的市场总盘子被大幅做大。

软件为数据管理、工作流业务逻辑、访问权限治理、数据保护等提供护栏。

Agent 在这些系统里、用这些数据执行任务，就像人一样，但规模远超人类，所以确定性控制比以往更重要。

软件和 Agent 会一起工作，最终大幅做大 IT 的 TAM。

English

Box CEO Aaron Levie uses this week's tech earnings calls to make a counterintuitive point about the software-vs-agents debate: they're not competitors, they're complements.

Software provides the deterministic guardrails—how data is managed, how access is governed, how workflows stay consistent. Agents work inside those systems to execute tasks at a scale no human team ever could. Which is exactly why the guardrails matter more, not less, as agents scale.

His conclusion: the best agents will be deployed inside established software platforms (Salesforce, Box, Harvey, ServiceNow), which can optimize them with vertical-specific evals and context. Net result—software and AI adoption rise together, and the IT TAM grows dramatically.

Software provides the guardrails for how data is managed, how business logic in workflows are maintained, how you manage and govern access to information, how you protect data, and more.

Agents, on the other hand, work inside these systems and with this data to execute on tasks just like people would have. But at a scale far greater than people ever did, which is especially why the deterministic controls matter more than ever.

Software and Agents are going to work together, and ultimately grow the size of the IT TAM dramatically as a result over time.
