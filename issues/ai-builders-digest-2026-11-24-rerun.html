Theme 02

Swarm Intelligence Has a Shape / Swarm 智能开始显现结构

多 agent 的收益不是简单堆数量，任务能否并行、agent 如何组织，决定了集体表现。

AM
Amjad Masad
@amasad
中文

Replit CEO Amjad Masad 分享了关于 agent swarm scaling laws 的新研究。在固定两小时窗口里，Opus 5.5 在 NumPy 任务上从单 agent 的 3.7 倍加速提升到 32 个 agent 的 18.9 倍，但 GPT-6.2 Astra 在超过 8 个 agent 后反而出现负向扩展。

结论不是“agent 越多越好”，而是“组织方式很重要”：去中心化 swarm 比中心化协调扩展得更好，任务能否并行是强预测指标，而单个模型的智能程度并不能很好预测集体智能。

扩大 agent 数量可以带来显著性能提升，但和传统 scaling laws 不同，更多 compute 不一定带来更好结果，agent 如何组织自己很重要。

去中心化 swarm 比依赖中心化协调的 swarm 扩展得更好。

单个模型的智能程度并不是集体智能的好预测指标。

English

Replit CEO Amjad Masad shares new research on scaling laws for agent swarms. With a fixed two-hour window, Opus 5.5 went from a 3.7x speedup with one agent to 18.9x with 32 agents on NumPy, but GPT-6.2 Astra showed negative scaling beyond eight agents.

The result is less 'more agents is better' than 'organization matters'. Decentralized swarms scaled better than centralized coordination, parallelizability predicted performance, and individual model intelligence was a poor predictor of collective intelligence.

Scaling the number of agents can yield dramatic performance gains, but unlike traditional scaling laws, more compute doesn't necessarily translate into better results, and how agents organize themselves matters.

Decentralized swarms scaled better than those that relied on centralized coordination.

Individual model intelligence is a poor predictor of collective intelligence.

服务业的变化不只是减少人手，而是让专家把判断放在前端，把执行产能交给 agent。

中文

Box CEO Aaron Levie 认为，agent 正在改变服务业的经济模型。过去产能基本跟 headcount 一起增长；agent 把产出和投入的人类时间解绑，一个 engineer 或 designer 可能做出过去几十个人的产出。

你会在网络安全、广告营销、法律、会计和 IT transformation 里看到这一点。

English

Box CEO Aaron Levie sees agents changing the economics of services businesses. Historically, output scaled with headcount; agents decouple output from the amount of human time, so one engineer or designer can potentially produce what dozens did before.

But his caveat is the important part: this is not simply 'all agents'. Experts still need to sit at the front end and ensure the right outcomes are delivered. He expects the pattern across cybersecurity, advertising, legal, accounting and IT transformation.

Agents entirely change the calculus here, because now we can scale output in a way that’s decoupled from the among of time that goes in.
