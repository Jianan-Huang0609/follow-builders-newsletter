Theme 02

Agents Need Context, Skills and Examples / Agent 需要上下文、技能与例子

当 agent 变强，单独展示一个 prompt 的解释力反而变弱；决定产出质量的是它能读取什么、调用什么，以及参考过哪些真实样本。

T
Thariq
@trq212
中文

Claude Code builder Thariq 认为，prompt 已经不是完整配方。现在他的 agent 会先看自己做过的 3 个 repo，再搜索网页资料、查 references，甚至调用其他 AI API，然后才开始工作。制作能力的单位因此从“写一句聪明指令”变成“准备好一个环境”：上下文和例子本身，正在成为产品的一部分。

现在基本不可能只“展示你的 prompt”了，因为一切都和 references、skills、examples 有关。

我经常先让 agent 看我做过的 3 个 repo，搜索网页资料，使用其他 AI API 等。

English

Claude Code builder Thariq argues that the prompt is no longer the whole recipe. His agents inspect three of his other repositories, search the web, consult references, and use other AI APIs before doing the work. That changes the unit of craft from a clever instruction to a prepared environment: context and examples are becoming part of the product.

it's basically impossible for someone to just "show you their prompt" now, because everything is about references, skills and examples

I often ask my agent to look at 3 other repos I've made first, search the web for references, use other AI APIs, etc.
